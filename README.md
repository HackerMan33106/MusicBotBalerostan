# 🎵 Discord Music Bot

Современный, быстрый и многофункциональный музыкальный бот для Discord с интерактивной панелью управления, умным поиском треков, системой чёрного списка и автоматическим развёртыванием через Docker & GitHub Actions.

---

## 🚀 Основные возможности

- **Умный поиск треков (YouTube, Spotify, SoundCloud)**:
  - Алгоритм приоритизации студийных версий (предпочтение официальным релизам и каналам *- Topic*, фильтрация живых выступлений, каверов и реакций).
  - Поддержка треков Spotify с мгновенным подбором лучшего аудиопотока по длительности и названию.
  - Полноценная команда `/search` с переключением платформ и выбором из 10 лучших результатов.
- **Интерактивная панель управления**:
  - Удобный UI с кнопками: воспроизведение/пауза, предыдущий трек, пропуск, остановка, просмотр очереди.
  - Защита от случайных нажатий: панелью могут управлять только участники, находящиеся в одном голосовом канале с ботом.
- **Система чёрного списка (`/bl`)**:
  - Блокировка нежелательных пользователей на уровне сервера с сохранением в базе данных SQLite (`blacklist.db`).
  - Быстрое управление: `/bl add @user`, `/bl remove @user`, `/bl list` (доступно администраторам).
  - Скрытая блокировка: заблокированный пользователь не может запускать музыку и использовать панель.
- **Автоматическое управление голосовым каналом**:
  - Авто-выход при пустом голосовом канале.
  - Таймер ожидания при завершении очереди треков.
  - Встроенный Watchdog для отслеживания состояния подключения.

---

## 🛠 Требования

- Python 3.10+ (для локального запуска) или [Docker](https://www.docker.com/) & [Docker Compose](https://docs.docker.com/compose/) (для запуска на сервере)
- [FFmpeg](https://ffmpeg.org/) (уже включен в Dockerfile)
- Токен Discord бота с включенными `Intents` (Server Members, Message Content, Voice States)
- Spotify API Client ID & Secret (опционально, для треков из Spotify)

## 💻 Локальный запуск (без Docker)

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/HackerMan33106/MusicBotBalerostan.git
   cd MusicBotBalerostan
   ```

2. **Создайте и активируйте виртуальное окружение**:
   ```bash
   # Windows
   python -m venv .venv
   .venv\Scripts\activate

   # Linux / macOS
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте `.env`**:
   ```bash
   cp .env.example .env
   ```
   Заполните ваши ключи в `.env`:
   ```env
   DISCORD_TOKEN=your_discord_bot_token_here
   SPOTIFY_CLIENT_ID=your_spotify_client_id_here
   SPOTIFY_CLIENT_SECRET=your_spotify_client_secret_here
   ```

5. **Запустите бота**:
   ```bash
   python main.py
   ```

## 🐳 Запуск через Docker Compose

```bash
# 1. Сборка и запуск контейнера в фоне
docker compose up -d --build

# 2. Просмотр логов бота в реальном времени
docker compose logs -f bot

# 3. Остановка контейнера
docker compose down
```

## 🔄 Автоматический CI/CD Деплой (GitHub Actions)

При каждом `git push` в ветку `main` пайплайн [.github/workflows/main.yml](.github/workflows/main.yml):
1. Подключается к вашему VPS по SSH.
2. Останавливает текущий контейнер и делает бэкап папки данных `data/` (сохраняя базу `blacklist.db`).
3. Подтягивает свежий код из репозитория.
4. Восстанавливает данные `data/`.
5. Генерирует `.env` файл из секретов GitHub.
6. Собирает Docker образ и запускает бота (`docker compose up -d`).
7. Очищает старые неиспользуемые Docker-образы.

## 📜 Доступные команды

| Команда | Описание |
|---|---|
| `/play <ссылка или запрос>` | Воспроизвести трек (YouTube, Spotify, SoundCloud, MP3) |
| `/search <запрос> [источник]` | Интерактивный поиск треков с переключением источников |
| `/bl` | Просмотр чёрного списка (для админа) или проверка своего статуса |
| `/bl action:add user:@пользователь` | Добавить пользователя в чёрный список сервера |
| `/bl action:remove user:@пользователь` | Убрать пользователя из чёрного списка сервера |
| `/bl user:@пользователь` | Проверить статус конкретного пользователя |
